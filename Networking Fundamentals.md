Networking Fundamentals 

LAN vs WAN 

LAN (Local Area Network) 

Covers a small geographic area (e.g., home, office, school). 

Used for resource sharing like files and printers. 

Example: A home Wi-Fi network. 

WAN (Wide Area Network) 

Covers a large geographic area and connects multiple LANs together. 

The internet is the largest example of a WAN. 

 
 

Core Network Devices 

Switch 

Connects multiple devices within the same network (LAN). 

Reduces congestion and manages data flow efficiently. 

Operates at the Data Link Layer (Layer 2) of the OSI model. 

Router 

Directs data between different networks (like LAN to WAN). 

Acts as a “traffic controller,” ensuring data reaches the correct destination. 

Operates at the Network Layer (Layer 3). 

Firewall 

Monitors and controls incoming and outgoing network traffic. 

Provides security by blocking unauthorized access. 

Can be hardware-based, software-based, or both. 

 
 

IP and MAC Addressing 

IP Address (Internet Protocol Address) 

Unique identifier for a device on a network. 

Enables communication between devices across networks. 

Two main types: 

IPv4: 32-bit address, written as four decimal numbers (e.g., 192.168.0.1). 

IPv6: 128-bit address, written as eight groups of hexadecimal numbers – supports far more devices. 

MAC Address (Media Access Control) 

48-bit unique identifier assigned to a network interface card (NIC). 

Used for communication within the local network (LAN). 

Works at the Data Link Layer (Layer 2). 

 
 

Ports and Protocols 

Ports 

Logical endpoints for communication. 

Ensure data reaches the correct application or service on a device. 

Example: Port 80 (HTTP), Port 443 (HTTPS), Port 25 (SMTP). 

Protocols 

Define the rules for data transmission and communication. 

HTTP/HTTPS: Web traffic 

SMTP: Email 

FTP: File transfer 

 
 

TCP vs UDP 

TCP (Transmission Control Protocol) 

Connection-oriented — requires a handshake before data transfer. 

Reliable and ensures data arrives in the correct order. 

Provides error-checking and flow control. 

Used for applications where accuracy matters (e.g., web browsing, email). 

UDP (User Datagram Protocol) 

Connectionless — sends data without prior communication setup. 

Faster but less reliable (no guarantee of delivery or order). 

Ideal for real-time applications like video streaming or gaming. 

 
 

Other Key Terms 

DNS (Domain Name System) 

Translates domain names (like www.google.com) into IP addresses. 

Works like the “phonebook” of the internet. 

VPN (Virtual Private Network) 

Creates a secure, encrypted connection over a public network. 

Protects data privacy and masks IP addresses.
